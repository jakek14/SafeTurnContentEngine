# LinkedIn — Channel Rules

Read `../CLAUDE.md` first for voice, pillars, audience, and industry facts. This file covers LinkedIn-specific formatting only.

## Format

- **Length:** 1,300–1,900 characters (~200–280 words)
  - Under 500 chars: flagged as low-effort by LinkedIn's algorithm
  - Over 2,000 chars: loses readers
- **Mobile-first formatting:** 1–2 sentences per paragraph, generous blank lines between sections
- **Bullet points:** when listing (3–5 max)
- **Emojis:** sparingly, 1–2 max per post as visual anchors. Never as decoration.

## The Hook (Critical)

- First **210 characters** must be scroll-stopping — this is the "See more" fold
- 60–70% of readers are lost at this point
- The hook's only job is to earn the next 5 seconds
- Use: data drops, story openers, contrarian statements, pattern interrupts

## Hashtags

- **3–5 hashtags** at the end of every post
- Mix: 2–3 broad + 1–2 niche
- Broad pool: `#SmallBusiness` `#Entrepreneurship` `#BusinessOwner` `#CashFlow` `#Finance` `#BusinessGrowth`
- Niche pool: `#DebtRestructuring` `#MCARelief` `#BusinessDebt` `#CashFlowManagement` `#CreditorNegotiation` `#BusinessTurnaround` `#DebtRelief` `#SMBFinance`
- 6+ hashtags triggers spam detection — never exceed 5

## Hard Don'ts

- **NEVER put links in the post body** — they cut reach by 40%. If there's a CTA link, note it separately for the first comment.
- No tagging random people for attention
- No "we" voice in hooks — save for authority sections

## Post Structure

1. **Hook** (1–2 lines, under 210 characters)
2. **Relatable problem or observation**
3. **Reframe** (challenge a common belief)
4. **Simple explanation** in plain language
5. **Light solution insight** (principle or framework, not a sales pitch)
6. **Soft CTA** (optional)
7. **Hashtags** (3–5)

## Output

Write the final post text only to `drafts/YYYY-MM-DD.md`. No PILLAR tag, no metadata in the file.
