# Instagram — Channel Rules

Read `../../CLAUDE.md` first for voice, pillars, audience, industry facts, and craft rules. This file covers Instagram-specific formatting only.

## Audience Note

Instagram's Safe Turn audience skews slightly younger (30–50), more visual-first, often scrolling early morning, lunch, or evenings. Less patient than FB readers — line 1 has to earn the tap to expand.

## Format

- **Length:** 500–900 characters (~80–150 words)
  - IG caption max is 2,200 chars but readers drop off fast
  - Tighter than FB, punchier, more emotional resonance
- **Paragraph style:** very short paragraphs, 1–2 lines each, with blank lines between
- **Emojis:** allowed sparingly, 0–2 per post, never as bullets or decoration

## The Hook (Critical)

- **First line is everything on Instagram.** IG truncates at ~125 characters with "... more"
- The first line must work as a **standalone hook** even if no one taps to expand
- Imagine the first line is the only thing that ever gets read — does it land on its own?
- Use: short declarative statements, data drops, contrarian one-liners, pattern interrupts
- Avoid burying the lede behind a setup sentence

Bad first line: *"Running a small business is hard, and one of the things I see often is..."*
Good first line: *"You know your exact bank balance without looking. That's not discipline. That's survival mode."*

## Hashtags

- **5–10 hashtags** — IG's algorithm uses them for discovery, more is fine
- Place at the end of the caption (or in first comment if you prefer cleaner caption — engine writes them at the end by default)
- Mix: 2–3 brand + 3–5 topical + 2 niche
- Brand: `#SafeTurnAdvisory` `#SafeTurn`
- Topical: `#SmallBusiness` `#SmallBusinessOwner` `#Entrepreneur` `#BusinessOwner` `#CashFlow`
- Niche: `#BusinessDebt` `#DebtRestructuring` `#MCARelief` `#CashFlowManagement` `#SMB` `#FinancialLiteracy` `#BusinessFinance`

## Links

- **No links in IG caption — period.** IG strips links to plain text and penalizes posts with URLs in caption
- CTAs go to "link in bio" only

## Visual Direction + Image Prompt (Required — Critical)

Instagram is image-first. The visual matters more than the caption. **Read `../image-style.md` for the full brand guide and prompt templates.** Each draft file must include three things:

1. A one-line `<!-- VISUAL: ... -->` HTML comment at the top (human-readable brief)
2. A full **`## Image Prompt`** block (paste-ready for Nano Banana or ChatGPT Image 2)
3. A **`## Text Overlay`** block (the headline + subtitle the human will add manually in Canva/Figma)

**Aspect ratio for Instagram:** 4:5 portrait (1080×1350) preferred for feed — fills more mobile screen and is the modern IG default. 1:1 (1080×1080) for grid consistency or carousel use. Never horizontal.

**IG safe zones for text overlay:** Keep all text within the center ~70% — IG overlays UI elements in the top 14% and bottom 35% (profile picture, username, like/comment/share/save buttons).

See `../image-style.md` Template A (Pull-Quote Card) for default prompt structure. ~90% of IG posts use Template A; Template B (Architectural Texture) only when the core idea is genuinely structural.

Reels not generated by this engine (separate workflow).

## Hard Don'ts

- No engagement bait ("Double tap if…", "Tag a friend who…")
- No links in caption
- No reposting Facebook caption verbatim — IG should be tighter, punchier, line-1 hook
- No reposting LinkedIn caption verbatim — LinkedIn is text-heavy B2B; IG is visual-first

## Post Structure

1. **Visual direction** (HTML comment at top of file — critical for IG)
2. **Line 1 hook** (works standalone at thumbnail)
3. **1–2 short paragraphs** of relatable problem or reframe
4. **Sharp close** (one-liner, no soft setup needed)
5. **Hashtags** (5–10)

## Output

Write the visual direction comment + final caption text only to `drafts/YYYY-MM-DD.md`. No PILLAR tag, no metadata beyond the visual comment.
